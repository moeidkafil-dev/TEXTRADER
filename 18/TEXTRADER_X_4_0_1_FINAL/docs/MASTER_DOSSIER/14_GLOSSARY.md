# Glossary

**Agent** — یک مؤلفه تحلیل‌گر مبتنی بر مدل که خروجی ساختاریافته تولید می‌کند.

**Context** — مجموعه versioned اطلاعاتی که برای یک تصمیم در اختیار agent قرار می‌گیرد.

**Decision Contract** — schema و قواعدی که خروجی تصمیم باید رعایت کند.

**Risk Engine** — لایه اعمال محدودیت‌های ریسک و سیاست‌های غیرقابل دورزدن.

**Execution Guard** — آخرین دروازه کنترل قبل از ارسال درخواست اجرایی.

**Replay** — بازسازی زنجیره تصمیم با artifactها و versionها.

**Reconciliation** — تطبیق وضعیت مورد انتظار با وضعیت واقعی broker/exchange.

**Kill Switch** — مکانیزم توقف اضطراری مسیر اجرا.

**Circuit Breaker** — توقف خودکار در شرایط anomaly/failure تعریف‌شده.

**Model Registry** — ثبت نسخه مدل، تنظیمات و متادیتای inference.

**Prompt Registry** — ثبت نسخه prompt/system instruction.

**Memory** — داده‌های پایدار یا موقت مورد استفاده برای context و تاریخچه.

**Audit Lineage** — زنجیره قابل ردیابی از ورودی تا تصمیم، policy و execution.
