# تعریف پروژه

**نام فنی:** TRADER (textrader) — **برند:** XIR (اکسیر)

## تعریف یک‌جمله‌ای `[ORIGINAL]`
سیستمی زنجیره‌ای برای خودکارسازی فرایند تحلیل بازارهای مالی، تصمیم‌گیری و خرید/فروش.

## ماهیت `[ORIGINAL]`
ترکیبی: سیستم معاملاتی + Agent System + Decision System + زیرساخت.

## بیان دقیق‌تر `[INTERPRETATION]`
زنجیره‌ای از سه ایجنت مستقل: (۱) تصمیم اولیه، (۲) تلاش سیستماتیک برای یافتن همه مسیرهای شکست همان تصمیم، (۳) تصمیم نهایی با اختیار تغییر؛ سپس عبور از لایه‌های Risk / Validator / Guard و اجرا با ابزارهای Buy/Sell/Skip؛ همراه با معماری حافظه گسترده، اعلام به کاربر با پنجره وتو ۲ دقیقه‌ای و Kill Switch.

## مسئله
تصمیم‌های معاملاتی خودکار معمولاً یک مسیر دارند (تحلیل → اجرا) و نقد سیستماتیک و حاکمیت ریسک در آن ضعیف است.

## راه‌حل
جدا کردن «تولید تصمیم»، «نقد تخاصمی تصمیم» و «تصمیم نهایی»، به‌علاوه حاکمیت ریسک چندلایه و نظارت انسانی.

## بازار و مرزها
- تمام بازارهای مالی؛ مستقل از بروکر `[ORIGINAL]`
- خودمختار؛ فرمان توقف/رد کاربر سیستم را در حالت انتظار نگه می‌دارد `[ORIGINAL]`

## کاربردها
اجرای خودکار ترید؛ دستیار تصمیم؛ زیرساخت ایجنتی مالی؛ پلتفرم پژوهشی.

## هشدار مسئولیت
سیستم با پول واقعی کار می‌کند؛ هیچ سندی این بسته سود تضمین نمی‌کند. فصل 17 (بک‌تست و paper trading) قبل از live الزامی پیشنهاد شده است.
