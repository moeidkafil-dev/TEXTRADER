# TRADER — Project Master Dossier
Version: 1.0
Date: 2026-09-22
Source architecture: `trader_final_architecture.graphml`

## Purpose
این بسته، مبنای مستندسازی، پژوهش، توسعه نرم‌افزار، حفاظت از مالکیت فکری و تبدیل معماری موجود به یک محصول قابل ساخت است.

## Source-of-truth rule
معماری فنی این بسته از فایل GraphML ارائه‌شده توسط صاحب پروژه استخراج شده است. هیچ جزء معماری حذف یا با معماری جایگزین ادغام نشده است؛ اسناد تحلیلی فقط آن را توصیف، سازمان‌دهی و برای ساخت محصول formalize می‌کنند.

1. `01_OWNER_AND_INVENTOR_DOSSIER.md` — پرونده مالک/مخترع، فقط بر اساس اطلاعات موجود؛ فیلدهای حقوقی نامعلوم خالی‌اند.
2. `02_PROJECT_IDENTITY_AND_SCOPE.md` — چیستی، مرز، کاربرد و دامنه.
3. `03_ORIGINAL_ARCHITECTURE_INVENTORY.md` — استخراج نودها/گروه‌ها و تفسیر آن‌ها.
4. `04_MASTER_TECHNICAL_SPECIFICATION.md` — specification سطح سیستم.
5. `05_RESEARCH_MONOGRAPH.md` — نوشتار پژوهشی سطح دانشگاهی/دکترا.
6. `06_PATENT_DISCLOSURE_DRAFT.md` — disclosure و draft اولیه پتنت؛ جایگزین وکیل/جستجوی prior art نیست.
7. `07_CLAIM_STRATEGY_AND_CLAIMS_DRAFT.md` — راهبرد ادعاها و ادعاهای پیشنهادی.
8. `08_COMPLETE_PRD.md` — PRD کامل و build-ready.
9. `09_SUPER_PROMPT.md` — super prompt برای تیم/Agent سازنده.
10. `10_SECURITY_THREAT_MODEL.md` — تهدیدها و کنترل‌های امنیتی.
11. `11_TEST_VALIDATION_AND_BENCHMARK_PLAN.md` — تست، validation، backtest و benchmark.
12. `12_IP_EVIDENCE_AND_CHANGE_LOG.md` — دفترچه شواهد مالکیت فکری و تاریخچه تغییرات.
13. `13_BUILD_ROADMAP.md` — roadmap اجرایی از prototype تا production.
14. `14_GLOSSARY.md` — واژه‌نامه رسمی.

## Important legal note
این بسته «draft فنی/حقوقی» است، نه اظهار نظر حقوقی و نه تضمین ثبت اختراع. برای ثبت واقعی باید jurisdiction، نام قانونی مالک، inventorship، prior-art search، تاریخ‌های disclosure و قوانین کشور هدف توسط متخصص مالکیت فکری بررسی شوند.
