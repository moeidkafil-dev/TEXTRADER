AI / LLM PROVIDER

Switch between a local model (Ollama, no API key, no internet), any API-key provider, or the built-in deterministic mock — with no code changes. Restart the process after switching for it to take full effect.

To point at a provider: set the matching env var before starting the panel/CLI — OLLAMA_HOST + OLLAMA_MODEL for a local model, OPENAI_API_KEY (+ optional OPENAI_BASE_URL for any OpenAI-compatible vendor), or ANTHROPIC_API_KEY. No package installs required — all providers use plain HTTP.

WHY THIS MATTERS

Agents 1–3 never talk to a vendor SDK directly — they call one adapter (LLMAdapter). Adding a new vendor later is one small class, not a rewrite.

EXTERNAL SOURCE CONNECTORS

Give the system a new outside source with just an API key + URL, or — at minimum — a plain webpage link to read. The research/knowledge layer can then draw on it by name.

HOW IT'S USED

Every connector is stored in config/connectors.yaml and reachable from the CLI (textrader connector …), this panel, or code via get_connector(name) — the same object, everywhere.

MODULE ROADMAP

Active modules are live now. Reserved modules are architected for (config fields / hooks already exist) but not yet built — added here first so extending the system later never means restructuring it.
