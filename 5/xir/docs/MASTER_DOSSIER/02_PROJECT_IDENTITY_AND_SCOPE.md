# Project Identity & Scope

## Working title
**TRADER — AI-Orchestrated Trading Decision, Risk, Memory and Execution System**

عنوان حقوقی/تجاری نهایی هنوز تعیین نشده است.

## What it is
یک سامانه نرم‌افزاری برای دریافت و پردازش داده‌های بازار، ساخت context، استفاده از چند مؤلفه/عامل هوش مصنوعی برای تحلیل و تصمیم‌سازی، نگهداری memory/database، ارزیابی تصمیم، اعمال کنترل‌های ریسک و هدایت فرآیند اجرای معامله.

## What it is not
- صرفاً یک chatbot نیست.
- صرفاً یک indicator نیست.
- صرفاً یک signal generator نیست.
- صرفاً یک LLM wrapper نیست.
- نباید به‌عنوان تضمین سود یا پیش‌بینی قطعی بازار تعریف شود.

## Core lifecycle
`data → context → analysis → decision → validation → risk → execution → monitoring → memory/audit`

## Intended applications
- research assistance
- strategy analysis
- decision support
- paper trading
- controlled live execution
- portfolio monitoring
- explainable trade review
- historical decision replay
- multi-agent market analysis

## Product boundary
The system can be deployed as:
- personal research platform;
- professional trading workstation;
- API service;
- multi-tenant SaaS;
- institutional internal platform.

Commercial and regulatory positioning must be decided per jurisdiction.
