## 2. Authorship / origin statement
بر اساس اطلاعات پروژه، معماری حاضر توسط صاحب پروژه طراحی و به‌صورت یک GraphML معماری ارائه شده است. این سند درباره مالکیت حقوقی نتیجه‌گیری قطعی نمی‌کند؛ مالکیت و inventorship باید با سوابق توسعه، commitها، فایل‌های اولیه، قراردادها و قوانین jurisdiction بررسی شود.

## 3. Evidence to preserve
- Original GraphML file.
- Hash of every released architecture version.
- Git repository and signed commits.
- Design notes and dated exports.
- Prompt/specification versions.
- Prototype source code.
- Test logs and benchmark results.
- Screenshots/exports of architecture.
- Records of public disclosure, if any.
- Contracts/assignments, if applicable.

## 4. Inventor contribution record
The project owner should document:
- problem formulation;
- system architecture;
- novel coordination mechanisms;
- decision/risk/execution boundaries;
- memory/context mechanisms;
- orchestration logic;
- validation and failure recovery;
- technical implementation;
- experimental evidence.

## 5. Do not fabricate
نام، تاریخ تولد، آدرس، ملیت، شرکت، هم‌مخترع، دانشگاه، مدرک تحصیلی یا سابقه کاری در این dossier ساخته نشده است.

## 6. Recommended legal evidence chain
`idea → dated design → architecture → prototype → experiment → revision → release`

برای هر مرحله یک timestamp، hash و immutable copy نگهداری شود.
