# 1. NON-NEGOTIABLE PRINCIPLE

Do not replace the original architecture with your own architecture.

Preserve the core design:

```text
DATA READER
    ↓
CONTEXT MAKER
    ↓
AGENT 1 — INITIAL ANALYSIS / DECISION
    ↓
AGENT 2 — ADVERSARIAL FAILURE ANALYSIS
    ↓
AGENT 3 — FINAL DECISION SYNTHESIS
    ↓
RISK / PROTECTIVE LAYER
    ↓
EXECUTION GUARD
    ↓
EXECUTION TOOL / BROKER
    ↓
MEMORY + AUDIT
```

The system must support:

```text
BUY
SELL
WAIT
RE-EVALUATE
```

`RE-EVALUATE` means restarting the complete decision pipeline from the Data Reader, not simply retrying the previous agent.

Human STOP / REJECT has absolute authority.

If the human issues STOP or rejects a decision:

```text
STOP
→ no autonomous execution
→ system waits for next explicit instruction
```

The execution layer must never bypass the protective layer.
