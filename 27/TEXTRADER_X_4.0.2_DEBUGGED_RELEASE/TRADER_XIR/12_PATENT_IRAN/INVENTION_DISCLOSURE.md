## مسئله فنی
در سیستم‌های تصمیم‌گیری خودکار، تصمیم تولیدشده بدون نقد ساختاری و بدون مانع قطعی قبل از ارسال سفارش اجرا می‌شود.

## راه‌حل فنی (از گراف — ORIGINAL)
1. ماژول خواندن داده + ساخت Context (داده+حافظه+تصمیم‌های قبلی+وضعیت+تنظیمات).
2. ایجنت اول: تصمیم اولیه.
3. ایجنت دوم: استخراج تمام مسیرهای شکست تصمیم اولیه.
4. ایجنت سوم: تصمیم نهایی از مجموعه {BUY,SELL,WAIT,RE-EVALUATE} با اختیار Override؛ RE-EVALUATE ⇒ بازگشت به ماژول خواندن داده.
5. زنجیره Risk Engine (۱۱ قاعده و Kill Switch) → Decision Engine → Validator → Risk → Execution Guard → Broker.
6. Message System: اعلام به کاربر؛ ۲ دقیقه؛ سکوت/OK اجرا، رد عدم اجرا.
7. معماری حافظه ۲۸گانه + Memory Manager با چرخه پاکسازی ۲ ساعته.

## مزایا
کاهش تصمیم‌های اجراشده با مسیر شکست شناخته‌شده؛ کنترل قطعی ریسک؛ ردیابی کامل؛ مداخله انسان.
